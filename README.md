Functional Requirements:-
- There will be an editor and user can write 
- Auto save functionality
- Maintain versions of the current document
- Cursor indicator
- There can be multiple pages 
- Infinite scroll for pages
- Single editor can edit the document

Non- functional Requirements:-
Performance:-
- Smooth scroll while scrolling
- Typing should be smooth

Reliability:-
- user can persist document when internet goes off or offline edit
- user should get the last edited word after internet goes off

Scalibility:-
- There can be multiple pages in the editor
